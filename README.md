# PhishGuard – Phishing Website Detection Using Supervised Machine Learning

**Author:** Aditya Bhatt (URN 2481184)  
**Course:** Applied Machine Learning  
**Dataset:** UCI Phishing Websites (dataset ID 327; 30 features; target `class`)

This is the runnable VS Code project corresponding to the report. It compares a DummyClassifier baseline with Logistic Regression, Decision Tree, Random Forest, RBF-SVM and KNN. It uses a leak-free scikit-learn pipeline, stratified 5-fold cross-validation, GridSearchCV, training-only threshold selection, a PCA experiment, and one final held-out test evaluation.

## 1. Requirements

- Python 3.10 or newer
- VS Code with the Python extension
- Internet connection for the first dataset download

## 2. Open and run in VS Code

Open the **PhishGuard** folder in VS Code. Open Terminal → New Terminal and run:

```bash
# Windows PowerShell
py -m venv .venv
.venv\Scripts\Activate.ps1

# Install packages
python -m pip install --upgrade pip
pip install -r requirements.txt

# Download the dataset
python download_dataset.py

# Train, compare, tune and evaluate the models
python train_model.py
```

If PowerShell blocks environment activation, use Command Prompt and run `.venv\Scripts\activate.bat` instead. You can also select the `.venv` interpreter from VS Code's Python interpreter selector.

Training can take several minutes because GridSearchCV evaluates multiple parameter combinations using five-fold cross-validation.

## 4. Run a prediction

The final model expects **30 pre-extracted UCI website features**, not a plain URL string. To use it, create a CSV containing the 30 feature columns in the same format as the dataset (the target column is optional), then run:

```bash
python predict.py path\to\your_feature_rows.csv
```

The output reports the phishing score and applies the report's 0.35 decision threshold.

### Important scope note

A plain URL cannot provide all 30 UCI features. Several features in the dataset depend on page HTML, DNS, domain registration, traffic or other external observations. The report's live PhishGuard concept describes an additional URL-only model and trusted-domain/rule components. Those additional models and data sources are not included in this course-project implementation. This version therefore makes predictions only when the 30 feature values are supplied; it does not visit or open submitted websites.

## 5. Methodology and interpretation

- Target mapping: `-1` (phishing) → `1`; `+1` (legitimate) → `0`.
- Split: 80% training / 20% test, stratified, `random_state=42`.
- Preprocessing: median imputation and StandardScaler inside a Pipeline/ColumnTransformer, fitted only within training folds.
- Model selection: GridSearchCV uses phishing recall as its refit metric.
- Threshold: Random Forest threshold 0.35, selected using out-of-fold training predictions under the report's 10:1 false-negative/false-positive cost.
- PCA: retain 95% variance and record the number of components.
- Test set: used once after tuning and threshold selection.

The project prints the actual metrics from the dataset version downloaded and the current software run. Do not hard-code report metrics as if they were generated by this run. Small differences can occur because the source CSV mirror/version and package versions may differ.

## 7. Safety and limitations

This is an academic demonstration, not a production security product. Predictions can be wrong, the dataset is historical, and model performance may not transfer to current phishing campaigns. Never enter credentials on a site based only on this model's output.
